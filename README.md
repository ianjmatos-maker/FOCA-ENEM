# FOCA ENEM

Repositório oficial do projeto **FOCA ENEM**.

Este repositório passa a ser a **fonte principal de verdade do código** do aplicativo. A regra de evolução é simples: novas versões devem preservar funcionalidades úteis existentes, registrar mudanças e evitar regressões silenciosas.

## Baseline inicial

A primeira baseline consolidada corresponde à edição **ESTUDAR HOJE**, baseada na linha completa v59, contendo Professor Foca adaptativo, prática, revisão, redação, planejamento, evolução e demais motores pedagógicos construídos até então.

O snapshot integral da baseline será mantido em `snapshots/` junto com um manifesto de integridade. A partir dele, o código será progressivamente organizado em estrutura definitiva sem apagar o histórico.

## Regras do projeto

- GitHub é a fonte oficial do projeto.
- Não substituir funcionalidades existentes sem migração explícita.
- Toda evolução relevante deve ser testável.
- Manter histórico e possibilidade de recuperação.
- Priorizar um produto funcional para estudo real do ENEM.
